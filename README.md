# Rock Paper Scissors – Console Game

This is a simple **Rock Paper Scissors** game made as part of [The Odin Project](https://www.theodinproject.com/) Foundations curriculum.

I first built the project in **JavaScript**, running entirely in the **browser console**, and then I also recreated it in **Python** for extra practice.

---

## Features

- Play 5 rounds of Rock, Paper, Scissors against the computer.
- The computer chooses randomly.
- The player enters their move manually.
- Tracks score and announces the winner at the end.
- Console-based only (no graphical interface).

---

## Versions

### ✅ JavaScript version

- Runs in the browser console.
- Files:
  - `index.html` (basic HTML file)
  - `Game.js` (contains all the game logic)
- How to run:
  1. Open `index.html` in a browser.
  2. Open the **DevTools Console**.
  3. Follow the prompts and check results in the console.

### ✅ Python version

- Runs in the terminal.
- File: `Game.py`
- How to run:
  1. Make sure you have Python installed.
  2. Run the script with: 
     ```bash
     python Game.py
     ```
  3. Follow the input prompts in the terminal.
